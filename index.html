Research Interests

My primary research interest is Reinforcement Learning, particularly applied RL in Data Science. I am interested in how sequential decision-making methods can be used to solve practical problems involving uncertainty, optimization, adaptation, and data-driven control.

I am also interested in applied Machine Learning and Deep Learning across different application domains.

Graph Theory holds a particularly strong personal appeal for me. Its structures, abstractions, and problem-solving perspectives genuinely intrigue me, and I enjoy exploring and brainstorming graph-based problems even outside formal academic work.

Selected Projects

Reinforcement Learning

RATE: Relative Amplitude TD Exploration

Developed an adaptive exploration method for reinforcement learning in which exploration is driven by the magnitude of the TD error relative to value estimates. The method was benchmarked against standard exploration strategies using tile-coded Sarsa(λ) and Double DQN across four Gymnasium environments.

Reinforcement Learning Exploration Sarsa(λ) Double DQN

Advanced Bioinformatics

Cross-Platform Benchmarking of Human PBMC Transcriptomic Data

Benchmarked Microarray, Bulk RNA-seq, and Single-Cell RNA-seq PBMC datasets using bioinformatics pipelines. The analysis compared cross-platform biological signals and investigated the effect of MAGIC-based imputation on single-cell data.

Bioinformatics Machine Learning RNA-seq

Probabilistic Machine Learning

Detection of Disease-Related Genetic Variants using BWT and Machine Learning

Developed a pipeline combining BWT-based sequence alignment, genetic variant identification, sparse machine learning, pathway-aware feature selection, and Markov Random Fields for modeling gene interactions and disease-related patterns.

Probabilistic ML Graphical Models Genomics
